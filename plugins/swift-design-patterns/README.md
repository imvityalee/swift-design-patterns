# Swift Design Patterns — Claude Code plugin

Catalog, idiomatic Swift examples, and recommendation guidance for the 23 GoF
design patterns. Markdown only: a skill with bundled references plus slash
commands — no MCP server, scripts, or dependencies.

- Skill: `swift-design-patterns` (auto-invoked for design-pattern work in Swift)
- Commands: `/pattern`, `/list-patterns`, `/recommend-pattern`,
  `/compare-patterns`, `/refactor-to-pattern`, `/swift-conventions`

The reference files under `skills/swift-design-patterns/references/` are
generated from the catalog in the repository's `src/` — edit there and run
`npm run build:plugin`.

## Install

```text
/plugin install swift-design-patterns --marketplace imvityalee/swift-design-patterns
```
